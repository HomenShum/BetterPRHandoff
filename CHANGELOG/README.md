# BetterPRHandoff — per-surface changelog index

These lanes record the current CLI and reusable lane-document changes. New
entries go at the top; historical entries are not rewritten. Read
[TEMPLATE.md](TEMPLATE.md) before adding an entry.

| Lane | What it covers |
| --- | --- |
| [scripts/bin-init.md](scripts/bin-init.md) | File scaffolding, preservation, and printed next steps |
| [components/changelog-lane.md](components/changelog-lane.md) | The reusable document for a surface's truthful change history |
| [components/qa-packet.md](components/qa-packet.md) | Static preview wrapping and unconfigured review-action disclosure |

The changelog-lane component describes a Markdown template. The QA-packet
component describes the generated static HTML; its visual proof is separate
from CLI file-generation checks.
Unavailable commit/author facts stay pending rather than being invented. The
original promotion observations remain unchanged outside this directory.
